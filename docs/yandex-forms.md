# Внешние формы больше не используются

Поддержка Яндекс Форм и FormSubmit исключена из генератора при подготовке исправлений обработки персональных данных. Установить эти значения `FORM_PROVIDER` больше нельзя.

Основной домен использует собственный SMTP-обработчик; статическая копия содержит переход на основной сайт. Настройка: [smtp-hosting.md](smtp-hosting.md). Юридические и организационные условия включения: [personal-data.md](personal-data.md). Фактическая публикация: [deployment.md](deployment.md).
